# Support

## PKS Notes

For PKS Notes support, [open an issue in this repository](https://github.com/moretea-labs/personal-knowledge-assistant/issues). Include the PKS Notes version, macOS version, reproducible steps, and the expected versus actual result.

PKS Notes does not require a PKS account or developer-operated server. Do not attach personal notes, PDFs, private file paths, credentials, tokens, or other private content to a public issue.

Security vulnerabilities, privacy concerns, and accidental data exposure must be reported through the private process in [SECURITY.md](SECURITY.md), not through a public issue.

## Personal Knowledge Assistant and Forge

Use this repository's Issues for reproducible Personal Knowledge Assistant defects and PKA-specific feature requests. Redact personal documents, source paths, tokens, and private content from public reports.

For Forge installation, plugin distribution, Controller behavior, or cross-provider questions, use [Forge Discussions](https://github.com/moretea-labs/forge/discussions).
