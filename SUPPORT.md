# Support

Use this repository's Issues for reproducible Personal Knowledge Assistant defects and PKA-specific feature requests. Redact personal documents, source paths, tokens, and private content from public reports.

For Forge installation, plugin distribution, Controller behavior, or cross-provider questions, use [Forge Discussions](https://github.com/moretea-labs/forge/discussions).

Security vulnerabilities and accidental data exposure must be reported privately; follow [SECURITY.md](SECURITY.md).
