# Security Policy

Do not report vulnerabilities or exposed personal data in public issues. Use GitHub **Private Vulnerability Reporting** for this repository.

Include the affected version, reproduction steps, impact, and whether the issue concerns source-root access, canonical writes, credential handling, derived indexes, HTTP API behavior, or the Forge provider protocol. Never attach real private documents or active credentials when a minimized fixture can reproduce the issue.

For vulnerabilities in Forge core rather than PKA, report them in the [Forge repository](https://github.com/moretea-labs/forge/security).
